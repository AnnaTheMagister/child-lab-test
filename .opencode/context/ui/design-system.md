# Design System — ChildLab

> У проекта есть макеты в Figma. Требования к цветам, размерам шрифтов и разметке жёсткие. Строим дизайн-систему с дизайн-токенами.

## Принципы

1. **Единый источник правды** — все токены в `assets/styles/variables.css`. Не дублировать значения.
2. **Figma → код** — цвета, размеры, отступы сначала появляются в Figma, потом переносятся в CSS-переменные.
3. **Градиенты и прозрачность** — всегда явно документировать. Использовать `rgba()` или `linear-gradient(...)`.
4. **UI-Kit приоритет** — новые интерфейсы строить из компонентов `src/scripts/ui-kit/`. Избегать inline-стилей.
5. **Не плодить сущности** — прежде чем добавить новую CSS-переменную, проверить, нет ли подходящей.

### Цветовые схемы кнопок

Определены в `src/scripts/ui-kit/Button/Button.tsx` (`COLOR_SCHEMES`):

- **grape**: фиолетовый градиент — primary схема
- **raspberry**: розово-пурпурный градиент — для фильтров курсов
- **strawberry**: красно-оранжевый градиент — запасная

### Кнопки — border-radius

Доступные значения в админке: `none`, `4px`, `6px`, `8px`, `10px`, `12px`, `16px`, `20px`, `32px`, `50%`.

По умолчанию: desktop/tablet = 8px, phone = 6px.

## Дизайн-ревью

Перед добавлением новой CSS-переменной или токена:
1. Проверить `variables.css` — нет ли подходящей
2. Проверить `COLOR_SCHEMES` в Button — может, цвет уже определён
3. Проверить Figma — соответствует ли значение макету
4. Добавить в этот файл документацию

### Что предлагать выносить в переменные
- Цвета, встречающиеся в inline-стилях React-компонентов
- Повторяющиеся `border-radius`, `padding`, `margin`
- Градиенты, используемые более чем в одном месте
- Размеры шрифтов в пикселях
